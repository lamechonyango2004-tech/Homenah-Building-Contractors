# Homenah Building Contractors

A website for **Homenah Building Contractors**, a building inspection and construction assurance business.

## About

Homenah Building Contractors offers professional building inspection services, including:
- Residential Inspections
- Commercial Inspections
- Site Inspections
- Renovations

The site includes service details, a project showcase, a contact form, and an FAQ chatbot for quick answers.

## Features

- **Responsive design** with a maroon and gold brand theme
- **Contact form** that sends inquiries directly to WhatsApp
- **FAQ chatbot** for quick answers about services, booking, location, and contact info
- **Login/sign-up page** (`login.html`) for client accounts, powered by Netlify Identity
- **Smooth scroll animations** for sections and cards as they come into view

## Tech Stack

- HTML, CSS, JavaScript (vanilla, no frameworks)
- Netlify Identity for authentication
- Hosted on GitHub Pages

## File Structure

```
├── index.html      # Main site page
├── login.html      # Client login/sign-up page
├── style.css        # Styling
├── script.js         # Interactivity (nav, contact form, chatbot)
└── favicon.svg      # Site icon
```
